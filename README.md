# لوحة الـ 600 ألف — جمعية رتّل لتحفيظ القرآن الكريم بنجران

برنامج متابعة يومي لخطة تغطية المصاريف التشغيلية بمبلغ 600,000 ريال (نوفمبر وديسمبر 2026).

## الملفات
| الملف | الوظيفة |
| --- | --- |
| `index.html` | البرنامج كاملاً (اللوحة، التسجيل، السجل، الرسائل) |
| `firebase-config.js` | إعدادات قاعدة البيانات المشتركة |
| `firestore.rules` | قواعد الوصول لقاعدة البيانات |

## 1) النشر على GitHub Pages
1. أنشئ مستودعاً جديداً في GitHub، مثلاً `ratl-600k`.
2. ارفع الملفات الثلاثة (Add file ← Upload files).
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يصبح الرابط: `https://اسم-الحساب.github.io/ratl-600k/`

بدون الخطوة الثانية تعمل اللوحة في **وضع تجريبي**: البيانات تُحفظ على الجهاز نفسه فقط.

## 2) ربط قاعدة بيانات مشتركة (Firebase مجاناً)
حتى يرى الفريق كله الأرقام نفسها مباشرة:
1. ادخل https://console.firebase.google.com وأنشئ مشروعاً جديداً.
2. من Build ← Firestore Database اضغط Create database (اختر موقعاً قريباً مثل `me-central2`).
3. من تبويب Rules الصق محتوى `firestore.rules` ثم Publish.
4. من إعدادات المشروع (Project settings) ← Your apps ← أيقونة الويب `</>` سجّل تطبيقاً، وانسخ قيم `firebaseConfig`.
5. الصق القيم في `firebase-config.js` وارفعه للمستودع.

## كلمات المرور بدون Firebase (داخل GitHub)
1. افتح `set-passwords.html` (على رابط الموقع أو من الجهاز) واكتب كلمة مرور لكل شخص ثم «توليد الملف».
2. انسخ الناتج، وفي GitHub افتح `auth-config.js` ← Edit ← الصق ← Commit.
3. بعد دقيقة تظهر شاشة الدخول. للتغيير كرّر الخطوات.

تنبيه: هذه حماية خفيفة تمنع الفضول فقط، لأن الكود عام ويمكن لمن يملك الوقت تخمين كلمات مرور ضعيفة. استخدم كلمات طويلة. والبيانات تبقى على كل جهاز ولا تُشارك بين الأربعة. للمشاركة والحماية الحقيقية استخدم Firebase.

## 3) كلمات المرور للأربعة (مع Firebase)
اللوحة تفتح بشاشة دخول: كل عضو يختار اسمه ويكتب كلمة مروره.
1. في Firebase اذهب إلى Build ← Authentication ← Get started ← فعّل **Email/Password**.
2. من تبويب Users اضغط Add user وأنشئ أربعة حسابات، البريد بالضبط ثم كلمة المرور التي تختارها أنت لكل شخص:
   - `director@ratl600k.app` (عبدالله الجليل)
   - `khalid@ratl600k.app` (خالد المصعبي)
   - `saleh@ratl600k.app` (صالح الطالبي)
   - `bassam@ratl600k.app` (بسام الأسمري)
3. في Firestore ← Rules الصق محتوى `firestore.rules` ثم Publish (يسمح لهذه الحسابات الأربعة فقط).
4. لتغيير كلمة مرور شخص: من Authentication ← Users ← القائمة ⋮ ← Reset password أو احذف الحساب وأنشئه من جديد.

> لا تضع كلمات المرور في أي ملف داخل المستودع (فهو عام). كلمات المرور تُحفظ في Firebase فقط.

> ما دام `firebase-config.js` فارغاً تعمل اللوحة بوضع تجريبي بدون كلمات مرور، والبيانات على الجهاز فقط.

## تعديل الأعضاء أو المبادرات
في `index.html` ابحث عن `const MEMBERS` و `const INITS` في بداية الكود، وعدّل الأسماء أو الأدوار.
المستهدف والمدة في السطر: `const START='2026-11-01', END='2026-12-31', TARGET=600000, DAILY=10000`
