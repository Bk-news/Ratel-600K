# لوحة الـ 600 ألف — جمعية رتّل لتحفيظ القرآن الكريم بنجران

برنامج متابعة يومي لخطة تغطية المصاريف التشغيلية بمبلغ 600,000 ريال (نوفمبر وديسمبر 2026).

## الملفات
| الملف | الوظيفة |
| --- | --- |
| `index.html` | البرنامج كاملاً (اللوحة، التسجيل، السجل، الرسائل) |
| `firebase-config.js` | إعدادات قاعدة البيانات المشتركة |
| `firestore.rules` | قواعد الوصول لقاعدة البيانات |

## 1) النشر على GitHub Pages
1. أنشئ مستودعاً جديداً في GitHub، مثلاً `ratl-600k`.
2. ارفع الملفات الثلاثة (Add file ← Upload files).
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يصبح الرابط: `https://اسم-الحساب.github.io/ratl-600k/`

بدون الخطوة الثانية تعمل اللوحة في **وضع تجريبي**: البيانات تُحفظ على الجهاز نفسه فقط.

## 2) ربط قاعدة بيانات مشتركة (Firebase مجاناً)
حتى يرى الفريق كله الأرقام نفسها مباشرة:
1. ادخل https://console.firebase.google.com وأنشئ مشروعاً جديداً.
2. من Build ← Firestore Database اضغط Create database (اختر موقعاً قريباً مثل `me-central2`).
3. من تبويب Rules الصق محتوى `firestore.rules` ثم Publish.
4. من إعدادات المشروع (Project settings) ← Your apps ← أيقونة الويب `</>` سجّل تطبيقاً، وانسخ قيم `firebaseConfig`.
5. الصق القيم في `firebase-config.js` وارفعه للمستودع.

## ملاحظة أمان
القواعد الحالية تسمح لأي شخص لديه الرابط بالتسجيل والحذف، وهذا مناسب لفريق صغير يحتفظ بالرابط داخلياً.
عند الحاجة لحماية أعلى يمكن إضافة تسجيل دخول للأعضاء (Firebase Authentication).

## تعديل الأعضاء أو المبادرات
في `index.html` ابحث عن `const MEMBERS` و `const INITS` في بداية الكود، وعدّل الأسماء أو الأدوار.
المستهدف والمدة في السطر: `const START='2026-11-01', END='2026-12-31', TARGET=600000, DAILY=10000`
